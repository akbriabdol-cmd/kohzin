# بستهٔ یکپارچهٔ کوه‌زین (KOHZIN)

این بسته رابط وب و API سرور را در یک پروژه قرار می‌دهد. فایل‌های رابط در `public/` هستند و `server.js` مسیرهای API را ارائه می‌کند.

## چه چیزهایی داخل پروژه به هم متصل شده‌اند؟
- `/api/health` برای بررسی وضعیت سرور و کلیدهای پیکربندی
- `/api/chat` برای دستیار متنی با Groq
- `/api/transcribe` برای تبدیل فایل صوتی به متن با Groq Whisper
- `/api/generate-video` برای ارسال درخواست تولید ویدیو به Kling از طریق fal.ai

## نکتهٔ مهم
این بسته به‌تنهایی به معنی اتصال به سرویس‌های آنلاین یا انتشار روی سایت زنده نیست. برای فعال شدن AI باید پروژه روی میزبان دارای Node.js منتشر شود و کلیدهای `GROQ_API_KEY` و `FAL_KEY` در بخش امن Environment Variables/Secrets همان میزبان ثبت شوند. کلیدها را در فایل HTML قرار ندهید.

## راه‌اندازی سرور
- Node.js نسخهٔ 20 یا بالاتر لازم است.
- دستور شروع: `npm start`
- مسیر بررسی سلامت: `/api/health`
- اگر رابط روی Droply و سرور روی دامنه‌ای جدا باشند، مقدار `FRONTEND_ORIGIN` باید دقیقاً `https://maple-summit-54.droply.id` باشد.
- پس از استقرار سرور جداگانه، در رابط کوه‌زین، بخش «ساخت ویدیو با هوش مصنوعی»، آدرس عمومی HTTPS سرور را در «آدرس سرور هوش مصنوعی» وارد و «ذخیره و آزمایش اتصال» را بزنید. این آدرس، کلید محرمانه نیست.

## وضعیت فعلی
فایل‌های رابط و سرور در این بسته کنار هم قرار گرفته و مسیرهای API در هر دو سمت بررسی شده‌اند. این بسته هنوز روی Render یا سایت Droply منتشر نشده و اتصال زندهٔ Groq/fal.ai آزمایش نشده است.
